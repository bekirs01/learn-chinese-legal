# Learn Chinese — public legal site

Privacy Policy and Support pages for **Learn Chinese** (Learn Chinese for Beginners).

This repository is **public** so App Store Connect can link HTTPS pages. It does **not** contain the Flutter application source.

The application repository `bekirs01/Learn-Chinese-for-Beginners` remains **private**.

## Pages

After GitHub Pages is enabled on `main` (root):

- Home: `/`
- Privacy: `/privacy.html`
- Support: `/support.html`

Support requests: [GitHub Issues](https://github.com/bekirs01/learn-chinese-legal/issues) (GitHub sign-in required).
